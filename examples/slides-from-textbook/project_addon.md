## Active template: slides-from-textbook

This is a slides project. The produced app is a downloadable, single-file HTML slide deck with arrow-key navigation, learning interactions, and optional in-browser editing for the teacher.

**Aesthetic discipline:** teaching imagery is not decoration. Every visual element should teach a named concept. Use at most five semantic colors and animate only when motion itself teaches something.

**Unit of content:** one slide-worth of knowledge. Chunking targets one teachable concept per chunk; extraction produces a concept, visual hint, and proposed component; rendering maps entries to the template's component system.

**Output shape:** one self-contained `.html` file with media inlined for offline use. The produced deck makes no runtime model calls; model work happens during the build.

Package produced knowledge byte-identically under `.claude/skills/` and `.agents/skills/`.
